### Core Protocol Structure

**ERC-8004: Agent Identity on EVM Chains**

ERC-8004 defines a standard interface for agent identity registration on EVM chains. The protocol consists of:

1. **Identity Registry Contract** - Stores agent metadata, capabilities, and trust scores
2. **Agent Identity NFT** - Non-transferable token representing agent identity
3. **Trust Oracle** - Optional reputation scoring mechanism

### Key Architectural Decisions

1. **NFT-based identity** - Enables composability with existing NFT tooling
2. **Sepolia-first deployment** - Testing ground before mainnet
3. **Optional trust oracle** - Flexibility over strong guarantees
4. **Metadata-heavy design** - Off-chain capability descriptions

### Critical Dependencies

- Base Sepolia network availability (testnet = lower reliability)
- Base Foundation registry maintenance
- External trust oracles (not deployed)

### Failure Modes

1. **Registry abandonment** - Testnet contracts may not migrate to mainnet
2. **Sybil spam** - Low cost to register fake agents
3. **Trust oracle centralization** - Single point of reputation failure
4. **Metadata rot** - Off-chain descriptions become stale
